# WaveStream

MP3・M4A・MP4（動画）などの音声を、無圧縮の Linear PCM（WAV）へ変換するブラウザツール。単一HTMLファイルで動作する。

## 設計

- **端末内で完結する** — ファイルはサーバへ送らない。デコードもリサンプリングも書き出しも、すべてブラウザ内で実行する。アップロードを伴う変換サービスに音声を預けずに済む。
- **デコードは標準APIに委ねる** — `decodeAudioData` を用い、ブラウザが備えるコーデックでデコードする。デコーダをWebAssemblyで同梱しないため、ファイルサイズが小さく、対応形式は閲覧環境に追従する。
- **不要な処理を行わない** — 出力設定が入力と同一の場合、リサンプリング工程を丸ごと省く。サンプルレートまたはチャンネル数が異なるときにのみ `OfflineAudioContext` を通す。無変更の音声に対して余計な変換を挟まない。
- **WAVヘッダを自前で構築する** — RIFF/WAVE のチャンクを直接組み立て、サンプルを16bit整数へ量子化して `Blob` として書き出す。ライブラリに依存しないため、出力形式の内訳が全て可視である。

## 対応形式

| | |
| --- | --- |
| 入力 | MP3, M4A, MP4（動画からの音声抽出）, WAV, OGG, AAC |
| 出力 | WAV（Linear PCM 16-bit） |
| サンプルレート | 元の値を維持 / 48,000 Hz / 44,100 Hz |
| チャンネル | 元の値を維持 / 2ch / 1ch |

## 用途

波形編集ソフトやAI文字起こしは、非可逆圧縮を経ていない音声を入力としたときに精度が安定する。本ツールは、その前段の形式変換を手元で済ませるために作成した。

## 依存

Tailwind CSS・Font Awesome・Google Fonts をCDNから読み込む。音声処理は Web Audio API のみで、第三者ライブラリを同梱していない。
